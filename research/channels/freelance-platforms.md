# 프리랜서 플랫폼 (크몽/숨고/위시켓)

## 플랫폼 비교

| 항목 | 크몽 | 숨고 | 위시켓 |
|------|------|------|--------|
| 특성 | 디지털 서비스 | 생활 서비스 | IT 외주 |
| 강점 | 봇/자동화/디자인 | 요가/과외/레슨 | 개발 프로젝트 |
| 서비스 수 | 60만+ | - | - |
| 거래 건수 | 640만+ | - | - |

## 크몽 자동화 봇 시장
- 등록된 봇/챗봇 서비스: 807개
- 업무 자동화 개발 비용: 30만~200만원
- 카테고리: 웹 스크래핑, 엑셀 매크로, API 연동, 챗봇

## 현실적 어려움
- 요청마다 커스텀 코딩 필요 (재사용 어려움)
- 웹사이트 구조 변경으로 유지보수 지속
- 수정 요청이 끝없이 발생

## 진입 전략
1. 상위 판매자 서비스 구성/가격 벤치마킹
2. 초기 1-2개월: 경쟁 가격 20-30% 할인
3. 리뷰 5개 이상 확보 후 정상 가격
4. 반복 판매 가능한 "패키지형" 서비스 설계

## 수익 시뮬레이션
- 자동화 봇 1건: 50만원 (보수적)
- 월 2건 수주 = 100만원 = 주 25만원 (목표 초과 달성)
- 하지만 수주 불안정성이 리스크

## 추가 조사 필요
- [ ] 크몽 상위 자동화 서비스 10개 벤치마킹
- [ ] 숨고에서 개발자 서비스 현황 조사
- [ ] 위시켓 소규모 프로젝트 현황
