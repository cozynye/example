# 카페 예약 관리 시스템

## 한줄 요약
소규모 카페 사장이 인스타DM/전화/카톡으로 흩어진 예약을 한 곳에서 관리하는 심플한 웹앱

## 문제 정의
- **누가**: 소규모 카페 사장 (1인 카페, 디저트 카페, 예약제 카페)
- **무슨 문제**: 인스타 DM, 전화, 카톡으로 들어오는 예약을 수기로 관리 → 더블부킹, 노쇼, 확인 누락
- **얼마나 자주**: 매일 (영업일마다 반복)
- **현재 해결 방법**:
  - 수기 노트/엑셀
  - 네이버 예약 (무료지만 네이버 생태계 종속)
  - 인스타 DM 하나하나 확인

## 솔루션
- **무엇을 만드는가**: 모바일 친화적 웹앱 (PWA) - 예약 캘린더 + 고객 알림 + 노쇼 관리
- **핵심 기능 3가지**:
  1. 예약 캘린더 (날짜/시간/인원/메모) - 한눈에 예약 현황 파악
  2. 고객용 예약 페이지 (인스타 프로필 링크에 걸어두기)
  3. 카카오 알림톡 자동 발송 (예약 확인/리마인더)

- [x] 커뮤니티에서 카페 사장 DM 관리 고충 확인 (네이트판, 더쿠)
- [ ] 경쟁자 상세 가격대 조사
- [ ] 잠재 고객 인터뷰 (최소 3명) ← **다음 단계**
- **검증 근거**:
  - 인스타 감성 카페가 예약제로 운영하는 트렌드 (MBC 뉴스에서도 보도)
  - 카페 사장들의 인스타 DM 관리 불편 다수 커뮤니티 글
  - 소셜비즈 등 DM 자동화 솔루션 등장 = 시장 수요 증거
  - 한국 카페 수 10만+, 그 중 예약제 운영 비율 증가 중

## 경쟁 분석
| 경쟁자 | 가격 | 장점 | 단점 | 우리 차별점 |
|--------|------|------|------|------------|
| 네이버 예약 | 무료 (현장결제) | 무료, 네이버 노출 | 네이버 종속, 카페 맞춤X | 인스타 연동, 카페 특화 UX |
| 캐치테이블 | 유료 (고가) | 350만 사용자, 검증됨 | 대형 식당 위주, 소규모에 과함 | 심플함, 저렴함 |
| 테이블링 | 유료 | 웨이팅 특화 | 예약은 부가 기능 | 예약 관리가 핵심 |
| 수기 관리 | 무료 | 비용 없음 | 실수, 노쇼, 비효율 | 자동화, 알림 |

### 점수 계산
(2×0.25) + (4×0.20) + (2×0.15) + (4×0.15) + (5×0.10) + (5×0.10) + (3×0.05)
= 0.5 + 0.8 + 0.3 + 0.6 + 0.5 + 0.5 + 0.15 = **3.35**

### 왜 점수가 낮아졌는가?
- 시장 검증: 커뮤니티 글만으로는 부족. 실제 카페 사장에게 "이 서비스에 돈을 내시겠습니까?"를 물어본 적 없음
- 경쟁 강도: 네이버 예약이 무료. "왜 돈을 내야 하지?"라는 반론을 충분히 극복할 차별점이 불명확
- 이 아이디어는 **72시간 검증(카페 사장 인터뷰)을 통과하면** 충분히 진행할 가치가 있음

## 기술 스택
- Next.js 14+ (App Router)
- Supabase (DB + Auth + Realtime)
- Vercel (호스팅 - 무료 티어)
- 카카오 알림톡 API (예약 알림)
- Tailwind CSS + shadcn/ui

## MVP 범위 (2주 내)
1. **Week 1**: 예약 캘린더 + 관리자 대시보드 + 고객용 예약 페이지
2. **Week 2**: 카카오 알림톡 연동 + 인스타 프로필 링크 연동 + 결제 시스템

### MVP에서 제외 (v2)

- 매출/통계 대시보드
- 다중 매장 관리
- POS 연동

## 마케팅 전략
1. **인스타그램 직접 DM**: 예약제 카페 검색 → 사장님에게 무료 체험 제안
2. **아프니까사장이다 카페**: 카페 사장 커뮤니티에 후기/소개
3. **크몽 서비스 등록**: "카페 예약 관리 시스템 세팅" 서비스
4. **스토리텔링**: "카페 사장님, 인스타 DM 예약 정리 지치셨죠?"
