# 학원 출결/학부모 알림 시스템

## 한줄 요약
소규모 학원(태권도, 미술, 영어)이 학생 출결을 터치 한 번으로 기록하고 학부모에게 카톡 자동 알림을 보내는 웹앱

## 문제 정의
- **누가**: 1-3인 운영 소규모 학원 원장님 (태권도, 미술, 피아노, 영어, 수학)
- **무슨 문제**: 출석부를 수기로 관리, 학부모가 "우리 애 오늘 갔나요?" 매일 카톡 질문, 결석 학생 파악 누락
- **빈도와 강도**: 매일 × 심각 (학생 20-50명, 매 수업시간마다 출결 체크)
- **현재 해결 방법**: 종이 출석부 / 엑셀 / 학부모 단톡방에 수동 알림

## 솔루션
- **무엇을 만드는가**: 태블릿/모바일에서 출결 터치 → 학부모 카톡 자동 알림 PWA
- **핵심 기능 3가지**:
  1. 터치 기반 출결 체크 (학생 목록 → 터치 → 등원/결석/조퇴 기록)
  2. 학부모 카톡 자동 알림 ("○○이가 15:00에 등원했습니다")
  3. 출결 통계 대시보드 (월별 출석률, 결석 패턴)

## 경쟁 분석
| 경쟁자 | 가격 | 장점 | 단점 | 빈틈 |
|--------|------|------|------|------|
| 클래스팅 | 무료~유료 | 학교 중심, 규모 큼 | 학원용 아님, 과도한 기능 | 소규모 학원 특화 없음 |
| 하이클래스 | 유료 | 학교 공식 | 학원 미지원 | 학원 시장 부재 |
| 출석부 앱 | 무료~유료 | 심플 | 학부모 알림 없음 | 알림 자동화 부재 |
| 종이 출석부 | 무료 | 비용 없음 | 검색 불가, 알림 불가 | 디지털 전환 니즈 |

### 무료 대체재 존재 여부
- [x] 무료 대체재 있음 (종이, 엑셀) → 차별점: **학부모 자동 알림** (가장 큰 페인포인트)
- [ ] 대기업 플레이어 있음 → 소규모 학원 전용은 드뭄

### ERRC 분석 (블루오션)
- **제거**: 학교용 복잡한 행정 기능 (시험, 성적)
- **감소**: 초기 설정 (학생 이름만 등록하면 시작)
- **증가**: 학부모 실시간 알림, 모바일 편의성
- **창조**: 수업료 납부 알림, 결석 자동 전화 알림

## 수익 모델
- **가격**: 14,900원/월 (학생 30명 이하), 29,900원/월 (30명 이상)
- **목표 고객 수**: 7명 (첫 달)
- **주 10만원 달성 조건**: 유료 전환 7명 이상

## 기술 스택
- Next.js 14+ (App Router, PWA)
- Supabase (DB + Auth + Realtime)
- 카카오톡 알림 API
- Vercel (배포, 무료 티어)
- Tailwind CSS + shadcn/ui

## MVP 범위 (2주)
- **1주차**: 학생 등록 + 출결 체크 UI (터치 기반) + 관리자 대시보드
- **2주차**: 학부모 알림 (카톡) + 출결 통계 + 결제

## MVP 제외 사항
- 수업료 관리/결제
- 성적 관리
- 학부모 앱 (알림만, 앱 불필요)

## 마케팅 전략
1. 인스타/네이버 카페에서 소규모 학원 원장님 검색 → DM
2. 학원 운영 관련 네이버 카페 (학원장 커뮤니티)
3. 크몽: "학원 출결 시스템 설치 서비스"
4. "원장님, 학부모 '우리 애 갔나요?' 카톡에 지치셨나요?" 스토리
