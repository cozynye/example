# 부동산 매물 소개 페이지 빌더

## 한줄 요약
공인중개사가 매물 사진+정보를 입력하면 깔끔한 매물 소개 웹페이지를 자동 생성, 카톡/문자로 고객에게 공유

## 문제 정의
- **누가**: 공인중개사 (개인 중개사무소)
- **무슨 문제**: 매물 소개를 카톡에 사진+텍스트로 보내지만 지저분하고 비전문적
- **빈도와 강도**: 매일 × 불편 (매물 5-20건 관리, 고객에게 반복 전송)
- **현재 해결 방법**: 카톡 사진+텍스트 / 네이버 부동산 등록 / 직방/다방

## 솔루션
- **무엇을 만드는가**: 매물 정보 입력 → 프로페셔널한 1페이지 웹사이트 자동 생성
- **핵심 기능 3가지**:
  1. 매물 정보 입력 폼 (사진, 가격, 면적, 위치, 특징)
  2. 깔끔한 매물 페이지 자동 생성 (공유 가능한 URL)
  3. 카톡/문자 공유 버튼 + QR코드
