# 모바일 청첩장/초대장 빌더

## 한줄 요약
예비 부부가 5분 만에 모바일 청첩장을 만들고 카톡으로 공유하는 웹앱. RSVP 자동 수집.

## 문제 정의
- **누가**: 결혼 예정 커플, 돌잔치/생일/이벤트 주최자
- **무슨 문제**: 모바일 청첩장 제작 업체에 5-15만원 지불. 수정 어려움. RSVP 관리 수동.
- **빈도와 강도**: 인생 1-2회 × 높은 지불 의향 (결혼에는 돈을 아끼지 않음)
- **현재 해결 방법**: 바른청첩장/보이스카드(5-15만원) / 카카오톡 기본 청첩장(무료지만 단순) / 업체 외주

## 솔루션
- **무엇을 만드는가**: 템플릿 선택 → 정보 입력 → 모바일 청첩장 자동 생성 + RSVP 수집
- **핵심 기능 3가지**:
  1. 디자인 템플릿 10종 + 커스텀 (사진, 색상, 폰트 변경)
  2. 카카오톡/문자 공유 + 네이버 지도 연동
  3. 참석 여부(RSVP) 자동 수집 + 식사 인원 집계

## 수익 모델
- **무료**: 기본 템플릿 1종, 워터마크 있음
- **스탠다드**: 19,900원 (모든 템플릿, 워터마크 제거, RSVP)
- **프리미엄**: 39,900원 (커스텀 도메인, 방명록, 갤러리, 배경음악)

## 기술 스택
- Next.js 14+ (동적 라우팅 /invitation/[id])
- Supabase (DB + Auth + Storage: 사진 업로드)
- Vercel (배포, 무료)
- 카카오 공유 API (무료)
- 네이버 지도 API (무료 할당량)
- Tailwind CSS

## 무료 운영 가능 여부 ✅
- Vercel Hobby: 무료

- 카카오 공유 API: 무료
- 네이버 지도: 일 25,000건 무료
