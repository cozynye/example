# AI 콘텐츠 재활용 도구

## 한줄 요약
블로그 글 하나를 입력하면 SNS 포스트(인스타, 트위터, 링크드인) 10개로 자동 변환하는 AI 도구

## 문제 정의
- **누가**: 콘텐츠 마케터, 1인 크리에이터, 소규모 마케팅팀
- **무슨 문제**: 블로그 글을 SNS에 맞게 재가공하는데 시간 많이 소모
- **빈도와 강도**: 주 2-3회 × 불편 (시간 낭비지만 ChatGPT로 어느정도 해결)
- **현재 해결 방법**: ChatGPT 수동 프롬프트, 직접 작성, 마케팅 대행

## 솔루션
- **무엇을 만드는가**: 웹앱 - 블로그 URL 입력 → SNS별 최적화 콘텐츠 자동 생성
- **핵심 기능 3가지**:
  1. 블로그 → 인스타 캡션 5개 + 해시태그
  2. 블로그 → 트위터 스레드 10개
  3. 블로그 → 뉴스레터 요약 1개
