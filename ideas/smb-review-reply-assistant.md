# 소상공인 리뷰 응답 도우미

## 한줄 요약
네이버 플레이스/카카오맵/배달앱 리뷰에 AI 맞춤 답글을 1클릭으로 생성하는 웹앱

## 문제 정의
- **누가**: 음식점, 카페, 미용실, 펫샵 등 소상공인 사장님
- **무슨 문제**: 매일 쏟아지는 네이버/카카오맵/배민/요기요 리뷰에 답글 작성이 부담. 안 쓰면 고객 신뢰↓, 쓰면 시간 소모↑
- **빈도와 강도**: 매일 × 심각 (하루 5-20개 리뷰, 각각 맞춤 답글 필요)
- **현재 해결 방법**: 수작업 답글 / 복붙 기본 답글 / 아예 무시 / ChatGPT에 하나씩 복붙

## 솔루션
- **무엇을 만드는가**: 리뷰 텍스트를 붙여넣으면 감정/톤/키워드를 자동 분석해 맞춤 한국어 답글을 생성하는 웹앱
- **핵심 기능 3가지**:
  1. 리뷰 텍스트 입력 → AI 맞춤 답글 즉시 생성 (칭찬/불만/중립 자동 감지)
  2. 답글 톤 선택 (친근한/정중한/사과형) + 가게 특성 반영
  3. 답글 히스토리 관리 (어떤 리뷰에 뭐라고 답했는지 추적)

## 경쟁 분석
| 경쟁자 | 가격 | 장점 | 단점 | 빈틈 |
|--------|------|------|------|------|
| 리뷰닥터 | 유료 (미공개) | 4000+ 가맹점, 네이버 연동 | 가격 부담, 대형 가맹점 위주 | 소규모 업체 진입장벽 |
| ChatGPT | 무료~$20/월 | 범용 AI | 매번 프롬프트 작성, 한국 리뷰 맥락 부족 | 워크플로우 최적화 부재 |
| 수작업 | 무료 | 비용 없음 | 시간 소모, 퀄리티 불균일 | 자동화 니즈 |

### 무료 대체재 존재 여부
- [x] 무료 대체재 있음 (ChatGPT) → 차별점: **워크플로우 최적화** (1클릭 vs 5단계 프롬프팅)
- [x] 대기업 플레이어 있음 (리뷰닥터) → 니치: **소규모 업체용 저가/프리미엄 모델**

### ERRC 분석 (블루오션)
- **제거**: 복잡한 설정, 네이버 계정 연동 (초기 진입장벽)
- **감소**: 가격 (리뷰닥터 대비 50% 이하)
- **증가**: 답글 품질 (한국어 자연스러움, 업종별 톤), 사용 편의성
- **창조**: 프리미엄 모델 (일 5건 무료), 업종별 프리셋 (카페/음식점/미용실)

## 수익 모델
- **가격**: 프리미엄 14,900원/월 (일 5건 무료 → 무제한 업그레이드)
- **목표 고객 수**: 7명 (첫 달)
- **주 10만원 달성 조건**: 유료 전환 7명 이상

## 기술 스택
- Next.js 14+ (App Router)
- Supabase (사용자 계정 + 답글 히스토리)
- OpenAI/Claude API (답글 생성)
- Vercel (배포, 무료 티어)
- Tailwind CSS + shadcn/ui

## MVP 범위 (1주)
- **포함**: 리뷰 입력 → 답글 생성 (3가지 톤), 가게 프로필 설정, 히스토리 저장
- **제외**: 네이버 플레이스 자동 연동, 배달앱 연동, 팀 기능
