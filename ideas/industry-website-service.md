# 업종별 맞춤 홈페이지 제작 서비스 (1-2인 소상공인 특화)

## 한줄 요약
1-2인 소상공인(미용실, 동물병원)을 위한 업종별 포트폴리오 기반 **단일 페이지** 웹사이트 제작 서비스 (Productized Service)

## ✅ 결정사항 (2026-W14)
- **첫 타겟**: 미용실 + 동물병원
- **가격**: 50만원 (단일 페이지 기준, 요구사항에 따라 추가)
- **디자인 옵션**: 트렌디 스타일 vs 정석적 소개 스타일 (2가지 선택지 제공)

## 문제 정의
- **누가**: 1-2인 소규모 소상공인 (미용실, 삼겹살집, 카페 등)
- **무슨 문제**: 웹사이트가 없거나 오래됨. 온라인 존재감 부족으로 경쟁에서 밀림
- **빈도와 강도**: 매일 × 심각 (네이버/카카오 검색 필수 시대, 웹사이트 = 신뢰의 기본)
- **현재 해결 방법**:
  - 무료 툴(Wix, IM Creator) - 너무 복잡, 시간 없음
  - 웹에이전시 - 너무 비쌈 (100만원+)
  - 프리랜서(크몽/숨고) - 품질 불확실
  - 대부분은 그냥 **포기** (네이버/카카오맵만 사용)

## 솔루션
- **무엇을 만드는가**: 업종별 예시 사이트를 먼저 제작 → 포트폴리오로 활용 → 이메일/DM으로 제안
- **핵심 기능 3가지**:
  1. **업종별 단일 페이지 템플릿**:
     - **미용실**: 갤러리, 스타일리스트 소개, 가격표, 예약 링크
     - **동물병원**: 원장 소개, 진료 과목, 시설 사진, 진료시간, 예약/문의
  2. **디자인 옵션 2가지**:
     - **트렌디**: 모던한 레이아웃, 대담한 컬러, 애니메이션, 비주얼 중심
     - **정석**: 깔끔한 레이아웃, 정보 전달 중심, 신뢰감 강조
  3. **필수 기능 패키지**: 네이버/카카오맵 연동, 예약 링크, 인스타그램 피드 임베드, 모바일 최적화

## 왜 1-2인 소상공인이 좋은가? ⭐

| 비교 항목 | 대형 업체 | **1-2인 소규모** |
|----------|----------|---------------|
| **웹사이트 유무** | 이미 있음 | 없거나 오래됨 ✅ |
| **예산** | 높음 (대형 에이전시) | 20-50만원 가능 ✅ |
| **의사결정 속도** | 느림 (승인 단계 많음) | **빠름 (사장님 직접)** ✅ |
| **계약 난이도** | 어려움 (입찰, 제안서) | **쉬움 (DM/전화)** ✅ |
| **충성도** | 낮음 (가격 비교) | **높음 (관계 기반)** ✅ |
| **타겟팅** | 어려움 | **쉬움 (지역+업종)** ✅ |

## 왜 동물병원이 좋은 타겟인가? 🐾

| 특징 | 분석 | 장점 |
|------|------|------|
| **마케팅 중요도** | 신규 고객 유치가 생존 전략 | 웹사이트 = 필수 투자 ✅ |
| **업체 규모** | 대부분 1-2인 운영 (수의사 1명) | 의사결정 빠름 ✅ |
| **페이지 복잡도** | 단일 페이지로 충분 (소개, 진료 과목, 예약) | 제작 시간 짧음 ✅ |
| **신뢰 중요성** | 전문성 있는 웹사이트 = 신뢰 상승 | 고가 지불 의향 높음 ✅ |
| **경쟁 강도** | 동네마다 여러 병원, 차별화 필요 | 웹사이트로 차별화 가능 ✅ |
| **검색 빈도** | "근처 동물병원" 매일 검색됨 | SEO 가치 높음 ✅ |
| **예산** | 의료업 = 상대적으로 높은 수익 | 50만원 지불 가능 ✅ |

### 동물병원 vs 미용실 비교

| 항목 | 미용실 | 동물병원 |
|------|--------|----------|
| **지불 의향** | 중간 (20-30만원) | **높음 (50만원+)** ✅ |
| **신뢰 중요성** | 중간 | **매우 높음 (의료업)** ✅ |
| **웹사이트 필요성** | 선택 | **필수 (전문성 표현)** ✅ |
| **경쟁 타겟팅** | 경쟁자 많음 | 경쟁자 많지만 니치 ✅ |
| **단일 페이지 적합성** | 적합 | **매우 적합** ✅ |

> **결론**: 동물병원은 **높은 지불 의향 + 단일 페이지 적합 + 신뢰 중요**로 미용실과 함께 최우선 타겟

## 경쟁 분석
| 경쟁자 | 가격 | 장점 | 단점 | 빈틈 |
|--------|------|------|------|------|
| 웹에이전시 | 100만원+ | 전문성 높음 | 너무 비쌈, 소상공인 거부감 | 가격 |
| 크몽/숨고 프리랜서 | 20-80만원 | 저렴 | 품질 불확실, 포트폴리오 없음 | 신뢰/품질 |
| Wix/IM Creator | 무료~5만원/월 | 저렴 | 소상공인은 사용 못 함(기술장벽) | 복잡도 |
| 네이버 모두 | 무료 | 쉬움 | 못생김, 전문성 없어 보임 | 디자인 품질 |

### 무료 대체재 존재 여부
- [x] **무료 대체재 있음** → 하지만 **기술 장벽**으로 소상공인은 사용 못 함
- [ ] 대기업 플레이어 있음 → 틈새시장 (1-2인 소상공인은 대형 에이전시가 안 받음)

### ERRC 분석 (블루오션)
- **제거**: 복잡한 어드민 패널, 무한 커스터마이징 옵션
- **감소**: 제작 기간 (2주→3일), 가격 (100만원→30만원)
- **증가**: 업종별 맞춤화, 포트폴리오 기반 신뢰, 빠른 응답
- **창조**: 업종별 예시 사이트 먼저 제작 → 포트폴리오로 제안

## 수익 모델

### 가격 전략 ✅ (확정)
- **기본**: 50만원 (단일 페이지 기준)
- **추가 옵션**: 요구사항에 따라 추가 (예: 2페이지 구성 +20만원, 폼 기능 +10만원 등)
- **유지보수**: 월 5만원 (호스팅, 업데이트, 소소한 수정)

### 주 10만원 달성 조건
- **단기**: 제작비 50만원 × 월 1건 = 주 12.5만원 ✅
- **중기**: 제작비 50만원 × 월 2건 = 주 25만원 ✅✅
- **장기**: 유지보수 월 5만원 × 10곳 = 월 50만원 (주 12.5만원) + 신규 제작 = 주 25-37만원+

### 가격 정당화
| 항목 | 크몽/숨고 평균 | 우리 가격 | 차별점 |
|------|---------------|----------|--------|
| 단일 페이지 | 20-30만원 | **50만원** | ✅ 포트폴리오 기반 신뢰 + 업종 특화 + 디자인 2가지 옵션 |
| 품질 | 불확실 | **보장됨** | ✅ 포트폴리오로 사전 확인 가능 |
| 제작 기간 | 1-2주 | **3일** | ✅ 빠른 턴어라운드 |

#### 동물병원 단일 페이지 구성 (확정)
```
섹션 구성 (위→아래):

1. Hero (메인 비주얼)
   - 병원 외관 또는 대표 이미지
   - 병원명 + 짧은 태그라인 (예: "우리 동네 가족 같은 동물병원")
   - CTA 버튼 (예약하기, 위치 보기)

2. 병원장 소개
   - 프로필 사진 + 이름
   - 약력 (학력, 경력, 전문 분야)
   - 진료 철학 (1-2문장)

3. 진료 과목 (할 수 있는 것들)
   - 아이콘 + 과목명 (예: 내과, 외과, 피부과, 치과, 예방접종 등)
   - 간단한 설명 (1줄)

4. 시설 안내
   - 병원 내부 사진 (대기실, 진료실, 수술실 등)
   - 3-6장 갤러리

5. 진료 안내
   - 진료시간표 (요일별)
   - 휴진일 안내
   - 예약 방법 (전화, 카카오톡 등)

6. 위치 & 연락처
   - 네이버/카카오 지도 임베드
   - 주소, 전화번호, 주차 안내
   - SNS 링크 (인스타그램 등)

7. Footer
   - 사업자 정보
   - Copyright
```

#### 미용실 단일 페이지 구성
```
섹션 구성 (위→아래):

1. Hero (메인 비주얼)
   - 매장 분위기 사진 또는 시술 사진
   - 매장명 + 태그라인 (예: "당신만의 스타일을 찾아드립니다")
   - CTA 버튼 (예약하기, 스타일 보기)

2. 스타일리스트 소개
   - 프로필 사진 + 이름
   - 경력 & 특기 (컷, 펌, 염색 등)
   - 수상 이력 (있다면)

3. 스타일 갤러리
   - 시술 전후 사진 (6-12장)
   - 카테고리별 (컷, 펌, 염색, 클리닉 등)

4. 가격표
   - 서비스별 가격
   - 깔끔한 테이블 형식

5. 매장 안내
   - 영업시간
   - 휴무일
   - 예약 방법 (전화, 네이버 예약, 카카오톡)

6. 위치 & 연락처
   - 네이버/카카오 지도 임베드
   - 주소, 전화번호, 주차 안내
   - 인스타그램 피드 (최근 게시물 3-6개)

7. Footer
   - 사업자 정보
   - Copyright
```

#### 디자인 2가지 스타일

**스타일 A: 트렌디**
- 모던한 레이아웃 (비대칭, Bento 그리드)
- 대담한 컬러 (브랜드 컬러 강조)
- 부드러운 애니메이션 (스크롤 페이드인)
- 큰 타이포그래피
- 비주얼 중심 (사진 크게)

**스타일 B: 정석**
- 깔끔한 레이아웃 (좌우 대칭, 전통적 그리드)
- 차분한 컬러 (화이트, 그레이, 네이비 등)
- 애니메이션 최소
- 가독성 좋은 타이포그래피
- 정보 전달 중심 (텍스트 명확)

#### 공통 기능
- 모바일 최적화 (반응형 디자인)
- 네이버/카카오 지도 연동
- 예약 링크 (전화, 카카오톡, 네이버 예약)
- SNS 연동 (인스타그램)

   - 크몽/숨고 평균 (20-30만원)보다 높지만
   - ✅ 포트폴리오 기반 신뢰 (사전 확인 가능)

   - ✅ 빠른 턴어라운드 (3일)

3. **디자인 2가지 스타일의 차별화**:
   - **트렌디**: 젊은 타겟, 비주얼 중심 (미용실에 적합)
   - **정석**: 신뢰 중심, 정보 전달 (동물병원에 적합)
   - 고객이 선택할 수 있어 만족도 상승

4. **검증 속도**:
   - 포트폴리오 2개 = 6일
   - 타겟 리스트 수집 + 이메일 발송 = 1-2일
