# 펫 비즈니스 예약/CRM

## 한줄 요약
애견미용실/펫호텔이 예약+반려동물 프로필+알림을 한 곳에서 관리하는 심플 웹앱

## 문제 정의
- **누가**: 애견미용실, 펫호텔, 반려동물 유치원, 펫시터 운영자
- **무슨 문제**: 카톡/전화로 예약 관리, 반려동물별 특이사항(알러지, 성격, 미용 이력) 기억 불가, 이중 예약, 노쇼
- **빈도와 강도**: 매일 × 심각 (예약 3-15건/일, 각 반려동물 정보 파악 필요)
- **현재 해결 방법**: 수기 장부 / 엑셀 / 카톡 대화 스크롤 / 기억에 의존

## 솔루션
- **무엇을 만드는가**: 펫 비즈니스 전용 예약 캘린더 + 반려동물 프로필 CRM
- **핵심 기능 3가지**:
  1. 예약 캘린더 (날짜/시간/서비스/반려동물 선택, 모바일 최적화)
  2. 반려동물 프로필 카드 (견종, 체중, 알러지, 성격, 미용 이력, 보호자 연락처)
  3. 카카오톡 알림 자동 발송 (예약 확인 + 전날 리마인더)

## 경쟁 분석
| 경쟁자 | 가격 | 장점 | 단점 | 빈틈 |
|--------|------|------|------|------|
| 네이버 예약 | 무료 | 네이버 노출, 무료 | 범용 (펫 프로필 없음), 네이버 종속 | 펫 특화 기능 부재 |
| 펫닥/핏펫 | 무료~유료 | 펫 건강관리 | 병원 중심, 미용실용 아님 | 미용/호텔 예약 관리 미지원 |
| 수기/엑셀 | 무료 | 비용 없음 | 검색 불가, 알림 불가, 실수 잦음 | 디지털 전환 니즈 |

### 무료 대체재 존재 여부
- [x] 무료 대체재 있음 (네이버 예약) → 차별점: **펫 프로필** (견종/알러지/성격/미용이력)
- [ ] 대기업 플레이어 있음 → 펫 비즈니스 전용 예약/CRM은 한국에 거의 없음

### ERRC 분석 (블루오션)
- **제거**: 복잡한 POS 연동, 대규모 병원용 기능
- **감소**: 초기 설정 복잡도 (5분 이내 시작)
- **증가**: 반려동물 개별 관리 (프로필, 이력, 메모)
- **창조**: 미용 전/후 사진 기록, 다음 방문 추천 시기 알림

## 수익 모델
- **가격**: 19,900원/월 (14일 무료 체험)
- **목표 고객 수**: 6명 (첫 달)
- **주 10만원 달성 조건**: 유료 전환 6명 이상

## 기술 스택
- Next.js 14+ (App Router, PWA)
- Supabase (DB + Auth + Realtime)
- 카카오톡 알림 API
- Vercel (배포, 무료 티어)
- Tailwind CSS + shadcn/ui

## MVP 범위 (2주)
- **1주차**: 예약 캘린더 + 펫 프로필 카드 + 관리자 대시보드
- **2주차**: 고객 예약 페이지 (인스타 프로필 링크용) + 카톡 알림 + 결제

## MVP 제외 사항
- POS 연동, 정산 관리
- 직원 스케줄 관리
- 멀티 지점 관리
