# Next.js SaaS 보일러플레이트 키트

## 한줄 요약
한국 개발자를 위한 Next.js + Supabase + 토스페이먼츠 SaaS 스타터 키트 (1회 구매)

## 문제 정의
- **누가**: SaaS를 만들고 싶은 한국 개발자/인디해커
- **무슨 문제**: 매번 인증, 결제, 대시보드, 랜딩페이지를 처음부터 만듦. 설정에 2-4주 낭비
- **빈도와 강도**: 프로젝트마다 × 심각 (반복적인 보일러플레이트 작업)
- **현재 해결 방법**: ShipFast($199 영어), create-next-app(기본만), 직접 세팅

## 솔루션
- **무엇을 만드는가**: 한국 개발자를 위한 풀스택 SaaS 보일러플레이트
- **핵심 기능 3가지**:
  1. 인증 (Supabase Auth + 소셜 로그인) + 토스페이먼츠 결제 연동
  2. 관리자 대시보드 + 사용자 대시보드 + 랜딩페이지 템플릿
  3. 한국어 문서 + 배포 가이드 (Vercel) + SEO 설정

## 기술 스택 (키트에 포함되는 것)
- Next.js 14+ (App Router, Server Actions)
- Supabase (Auth + DB + Storage)
- 토스페이먼츠 (한국 결제)
- Vercel (배포)
- Tailwind CSS + shadcn/ui
- SEO 메타태그 + sitemap 자동 생성
- 이메일 (Resend)
- 에러 모니터링 (Sentry 기본 설정)

## MVP 범위 (2-3주)
- **1주차**: 인증 + 토스페이먼츠 결제 + 기본 대시보드
- **2주차**: 랜딩페이지 템플릿 + 관리자 패널 + 한국어 문서
- **3주차**: 배포 가이드 + 데모 사이트 + 판매 페이지
