# 이커머스 셀러 상품페이지 분석기

## 한줄 요약
스마트스토어/쿠팡 셀러가 상품 페이지 URL을 입력하면 AI가 개선점을 분석하고 경쟁 상품과 비교해주는 도구

## 문제 정의
- **누가**: 네이버 스마트스토어, 쿠팡 마켓플레이스 셀러 (1인 셀러~소규모 팀)
- **무슨 문제**: 상품 전환율이 낮은데 원인 파악 어려움. 컨설팅은 50-200만원
- **빈도와 강도**: 매주 × 불편 (상품 등록/수정 시마다 고민)
- **현재 해결 방법**: 감으로 수정 / 유료 컨설팅 / 경쟁사 벤치마킹 수동

## 솔루션
- **무엇을 만드는가**: 상품 URL 입력 → AI 기반 상세 페이지 개선 리포트
- **핵심 기능 3가지**:
  1. 상품 페이지 분석 (제목, 이미지, 가격, 리뷰 등 종합 평가)
  2. AI 개선 제안 (구체적 수정 사항)
  3. 경쟁 상품 비교 (동일 키워드 상위 상품 대비)
