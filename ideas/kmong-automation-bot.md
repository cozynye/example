# 크몽 자동화 봇 서비스

## 한줄 요약
크몽에서 비개발자들에게 업무 자동화 봇(스크래퍼, 엑셀 매크로, API 연동)을 제작/판매

## 문제 정의
- **누가**: 반복 업무에 시달리는 마케터, 사업자, 리서처
- **무슨 문제**: 수작업으로 데이터 수집, 엑셀 정리, 반복 입력
- **빈도와 강도**: 매일/매주 × 불편 (시간 낭비)
- **현재 해결 방법**: 수작업 or 크몽에서 외주 (30-200만원)

## 솔루션
- **무엇을 만드는가**: 크몽에 등록하는 자동화 봇 제작 서비스
- **핵심 기능 3가지**:
  1. 웹 스크래핑 봇 (경쟁사 가격, SNS 데이터 등)
  2. 엑셀/구글시트 자동화 (데이터 정리, 보고서 생성)
  3. API 연동 자동화 (슬랙/디스코드 봇, 알림 시스템)

## 점수 평가 (v2 — 새 스코어링)
| 기준 | 점수 (1-5) | 메모 |
|------|-----------|------|
| 시장 검증 (25%) | 4 | 크몽에 807개 서비스, 활발한 거래 = 수요 확인됨 |
| 수익 잠재력 (20%) | 4 | 건당 50만원 × 월 2건 = 주 25만원 |

### 점수 계산
(4×0.25) + (4×0.20) + (2×0.15) + (5×0.15) + (2×0.10) + (2×0.10) + (5×0.05)
= 1.0 + 0.8 + 0.3 + 0.75 + 0.2 + 0.2 + 0.25 = **3.50**
