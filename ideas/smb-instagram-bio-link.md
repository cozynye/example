# 소상공인 인스타 바이오 링크 도구

## 한줄 요약
소상공인이 인스타 프로필 링크 페이지를 5분 만에 생성 — 메뉴판, 예약, 위치, 영업시간을 한 페이지에

## 문제 정의
- **누가**: 인스타그램이 주 마케팅 채널인 소상공인 (카페, 미용실, 네일샵, 공방)
- **무슨 문제**: 인스타 프로필 링크 1개를 네이버 지도 하나로 낭비. 메뉴, 예약, 영업시간 등을 통합할 방법 없음
- **빈도와 강도**: 상시 × 불편 (프로필 링크 = 고객 유입의 핵심 경로)
- **현재 해결 방법**: Linktree (영문, 범용) / 네이버 지도 링크만 / 없음

## 솔루션
- **무엇을 만드는가**: 한국 소상공인 특화 바이오 링크 페이지 빌더
- **핵심 기능 3가지**:
  1. 한국형 템플릿 (메뉴판, 네이버지도, 카카오톡 채팅, 영업시간)
  2. 5분 만에 완성 (정보 입력 → 페이지 자동 생성)
  3. 커스텀 도메인 또는 서브도메인 (yourshop.mybio.kr)
