# 단축 URL + 클릭 분석 도구

## 한줄 요약
URL 단축 + 클릭 분석(위치, 기기, 시간대) + QR코드 자동 생성하는 마케팅 도구

## 문제 정의
- **누가**: 마케터, 인플루언서, 이커머스 셀러, 광고 운영자
- **무슨 문제**: Bit.ly는 무료 제한+영어, 클릭 분석이 부실. 어떤 링크가 잘 되는지 모름
- **빈도와 강도**: 콘텐츠/캠페인마다 × 불편
- **현재 해결 방법**: Bit.ly(무료 10개/월) / 직접 UTM 태그 / Google Analytics(복잡)

## 솔루션
- **무엇을 만드는가**: URL 단축 + 실시간 클릭 분석 대시보드 + QR코드
- **핵심 기능 3가지**:
  1. URL 단축 + 커스텀 슬러그 (yourlink.kr/event)
  2. 클릭 분석 (국가, 기기, 브라우저, 시간대, 리퍼러)
  3. QR코드 자동 생성 + 다운로드
