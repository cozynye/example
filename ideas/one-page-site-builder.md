# 한국형 1페이지 사이트 빌더 (Carrd 한국판)

## 한줄 요약
프리랜서/크리에이터/소상공인이 5분 만에 깔끔한 1페이지 웹사이트를 만드는 노코드 빌더

## 문제 정의
- **누가**: 인스타 크리에이터, 프리랜서, 사이드프로젝트 운영자, 소규모 이벤트
- **무슨 문제**: 간단한 소개 페이지/랜딩 페이지를 만들고 싶은데 코딩을 못 함. Notion으로 대체하지만 못생김
- **빈도와 강도**: 프로젝트마다 × 불편 (웹사이트 = 신뢰의 기본)
- **현재 해결 방법**: Linktree(단순) / Notion 공개 페이지(못생김) / Carrd(영어) / Wix(복잡)

## 솔루션
- **무엇을 만드는가**: 한국어 템플릿 기반 1페이지 사이트 빌더
- **핵심 기능 3가지**:
  1. 한국형 템플릿 10종 (포트폴리오, 이벤트, 가게소개, 링크모음, 이력서)
  2. 드래그&드롭 없이 폼 입력만으로 완성 (텍스트+이미지+링크 입력 → 자동 생성)
  3. 커스텀 도메인 또는 서브도메인 (yourname.mypage.kr)
