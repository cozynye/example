# AI OG 이미지/썸네일 생성기

## 한줄 요약
블로그 URL이나 텍스트를 입력하면 OG 이미지/유튜브 썸네일/배너를 AI로 자동 생성하는 도구

## 문제 정의
- **누가**: 블로거, 유튜버, 개발자 (기술 블로그), 마케터
- **무슨 문제**: 블로그 포스트마다 OG 이미지를 만들어야 하는데, Canva 열어서 하나하나 만들기 번거로움
- **빈도와 강도**: 콘텐츠 작성마다 × 불편 (5-15분/개)
- **현재 해결 방법**: Canva(수동) / 기본 OG 이미지(못생김) / Bannerbear(비쌈, API)

## 솔루션
- **무엇을 만드는가**: URL/텍스트 입력 → AI가 스타일 맞춤 OG 이미지 자동 생성
- **핵심 기능 3가지**:
  1. 블로그 URL 입력 → 제목/내용 추출 → 자동 이미지 생성
  2. 템플릿 선택 (미니멀, 그래디언트, 일러스트, 사진 배경)
  3. API 제공 (개발자가 자동화 가능, Vercel OG처럼)

## 경쟁 분석
| 경쟁자 | 가격 | 장점 | 단점 | 빈틈 |
|--------|------|------|------|------|
| Canva | 무료~유료 | 자유도 높음 | 수동, 시간 소모 | 자동화 없음 |
| Bannerbear | $49/월~ | API, 자동화 | 비쌈, 영어 | 개인/소규모 가격 부담 |
| Vercel OG | 무료 | 개발자용 | 코딩 필요, 디자인 한계 | 비개발자 사용 불가 |
| 기본 OG | 무료 | 비용 없음 | 못생김 | 디자인 퀄리티 |
