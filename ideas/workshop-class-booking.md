# 공방/원데이 클래스 예약 시스템

## 한줄 요약
도자기/캔들/가죽/플라워 공방 운영자가 클래스 일정+예약+결제를 한 곳에서 관리하는 웹앱

## 문제 정의
- **누가**: 원데이 클래스/공방 운영자 (도자기, 캔들, 가죽, 플라워, 향수)
- **무슨 문제**: 인스타 DM + 계좌이체로 예약/결제 관리. 일정 조율, 입금 확인, 취소 처리에 시간 소모
- **빈도와 강도**: 매일 × 심각 (인스타 DM이 주요 채널, 예약 3-10건/일)
- **현재 해결 방법**: 인스타 DM / 카톡 / 계좌이체 / 수기 장부

## 솔루션
- **무엇을 만드는가**: 공방 전용 예약+결제 원스톱 웹앱 (인스타 프로필 링크용)
- **핵심 기능 3가지**:
  1. 클래스 일정 공개 페이지 (날짜, 시간, 인원, 가격)
  2. 온라인 예약+결제 (토스페이먼츠 연동)
  3. 예약 관리 대시보드 (확인/취소/알림)

- **증가**: 결제 자동화 (입금 확인 불필요), 인스타 연동
