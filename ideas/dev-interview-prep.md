# 개발자 면접 준비 플랫폼

## 한줄 요약
한국 개발자 취업/이직 면접 질문+모범답안+모의면접을 제공하는 구독형 웹앱

## 문제 정의
- **누가**: 취업 준비 중인 주니어 개발자, 이직 준비 시니어 개발자
- **무슨 문제**: 면접 질문이 흩어져 있음 (블로그, GitHub, 노션). 체계적 학습 도구 부재. 모의면접은 비쌈(건당 5-10만원)
- **빈도와 강도**: 이직 시즌 × 매우 심각 (취업의 관문)
- **현재 해결 방법**: 블로그 검색 / GitHub 면접 질문 레포 / 유료 강의 / 친구와 모의면접

## 솔루션
- **무엇을 만드는가**: 프론트엔드/백엔드/CS 면접 질문 데이터베이스 + AI 모의면접
- **핵심 기능 3가지**:
  1. 기술별 면접 질문 모음 + 모범답안 (React, Node, CS기초, 시스템설계)
  2. AI 모의면접 (질문 → 답변 녹음/타이핑 → AI 피드백)
  3. 학습 진도 트래커 + 취약 분야 분석

## 수익 모델

## 기술 스택

- Supabase (DB + Auth)
- OpenAI/Claude API (AI 모의면접)

- Tailwind CSS + shadcn/ui
- 토스페이먼츠 (결제)

## MVP 범위 (2주)
- **1주차**: 면접 질문 DB (50문제+모범답안) + 카테고리 필터 + 사용자 인증
- **2주차**: AI 모의면접 (텍스트 기반) + 결제 연동 + 진도 트래커
- **콘텐츠**: React/Next.js 면접 20문제 + CS기초 20문제 + 시스템설계 10문제
