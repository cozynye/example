# 크몽/숨고 셀러 대시보드

## 한줄 요약
크몽/숨고/위시켓 활동 프리랜서가 의뢰 현황, 수익, 일정을 한눈에 관리하는 대시보드 웹앱

## 문제 정의
- **누가**: 크몽/숨고/위시켓 등 복수 플랫폼에서 활동하는 프리랜서
- **무슨 문제**: 플랫폼별 대시보드가 따로, 수익/일정을 엑셀로 통합 관리, 마감 놓침
- **빈도와 강도**: 매주 × 불편 (월 3-10건 프로젝트 동시 진행)
- **현재 해결 방법**: 각 플랫폼 + 엑셀/노션 수동 관리

## 솔루션
- **무엇을 만드는가**: 프리랜서 수익/프로젝트 통합 관리 대시보드
- **핵심 기능 3가지**:
  1. 프로젝트 트래커 (상태, 마감일, 금액, 플랫폼별)
  2. 월별 수익 차트 + 세금 계산
  3. 일정 알림 (마감 D-3, D-1)
