# 고객 후기 수집/임베드 위젯 (한국형)

## 한줄 요약
스마트스토어/자사몰 운영자가 고객 후기를 수집하고 웹사이트에 위젯으로 임베드하는 도구

## 문제 정의
- **누가**: 스마트스토어, 카페24, 자사몰 운영자 / 프리랜서 / 서비스 제공자
- **무슨 문제**: 고객 후기를 모으기 어려움. 모아도 예쁘게 보여줄 방법 없음. 카톡 캡처를 이미지로 붙이는 수준
- **빈도와 강도**: 상시 × 불편 (후기 = 전환율 핵심)
- **현재 해결 방법**: 카톡 캡처 스크린샷 / 네이버 리뷰 캡처 / 직접 HTML 코딩

## 솔루션
- **무엇을 만드는가**: 후기 수집 폼 + 자동 위젯 생성 도구
- **핵심 기능 3가지**:
  1. 후기 수집 페이지 (링크 공유 → 고객이 텍스트/별점/사진 제출)
  2. 위젯 임베드 (복붙 코드 1줄로 어디든 삽입, 슬라이드/그리드/월)
  3. 후기 관리 대시보드 (승인/숨김/베스트 선정)

## 기술 스택
- Next.js 14+ (수집 폼 + 대시보드)
- Supabase (DB + Auth + Storage)
- 임베드 위젯: React → 빌드 → CDN에서 `<script>` 로 로드
- Vercel (배포)
- Tailwind CSS + shadcn/ui

## MVP 범위 (2주)
- **1주차**: 후기 수집 폼 (텍스트+별점+사진) + 관리 대시보드
- **2주차**: 임베드 위젯 (슬라이드형) + 결제 + 랜딩페이지
