# 스마트 폼 빌더 (한국형 Typeform)

## 한줄 요약
설문/신청서/주문서를 드래그 없이 만들고, 응답을 자동 수집+알림하는 웹앱

## 문제 정의
- **누가**: 마케터, 이벤트 기획자, 동아리/모임 운영자, 소규모 팀
- **무슨 문제**: Google Forms는 못생기고, Typeform은 영어+비쌈. 한국어+한국 결제+예쁜 폼 도구가 없음
- **빈도와 강도**: 이벤트/프로젝트마다 × 불편
- **현재 해결 방법**: Google Forms(무료, 못생김) / Typeform($25/월, 영어) / Tally(무료, 영어) / 네이버 폼(기능 제한)

## 솔루션
- **무엇을 만드는가**: 한국어 폼 빌더 + 자동 응답 알림 + 데이터 대시보드
- **핵심 기능 3가지**:
  1. 폼 에디터 (질문 타입: 텍스트, 선택, 날짜, 파일, 별점 등)
  2. 자동 알림 (응답 시 카톡/이메일 자동 알림)
  3. 응답 대시보드 (차트, 엑셀 다운로드, 필터)
