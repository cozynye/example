# DM 스크립트 — 리뷰 답글 서비스

## 전략
- 첫 DM에서 절대 판매하지 않기
- 1차: 공감 → 2차: 문제 확인 → 3차: 솔루션 제안
- 타겟: 네이버 플레이스에서 리뷰 미답변이 많은 가게

---

## 인스타 DM 스크립트

### 1차 DM — 공감 (첫 접촉)

**타겟 찾는 법**: 
- 네이버 플레이스에서 동네 음식점/카페 검색
- 리뷰 10개+ 중 미답변 50% 이상인 가게 선별
- 해당 가게의 인스타 계정 찾기

**메시지**:
```
사장님 안녕하세요! 
[가게명] 자주 가는 단골인데요 ☺️
(or: [가게명] 인스타 보고 분위기가 너무 좋아서 가보고 싶어요!)

혹시 바쁘신 중에 실례가 안 된다면 
하나 여쭤봐도 될까요?
```

### 2차 DM — 문제 확인 (답변 오면)

**메시지**:
```
감사합니다 사장님!

다름이 아니라 저도 지인이 가게를 운영하고 있는데,
네이버 리뷰 답글 쓰는 게 매일 부담이라고 하더라고요.

사장님은 리뷰 답글 관리를 어떻게 하고 계신가요?
혹시 시간이 부족하거나 어려운 점이 있으신지 궁금해서요!
```

### 3차 DM — 솔루션 제안 (문제 공감 시)

**메시지 A (부담 있다고 하면)**:
```
아 역시 그러시군요ㅠ 
사장님만 그런 게 아니라 대부분 그러시더라고요.

저는 개발자인데, 지인 가게 도와주다가
리뷰 내용에 맞는 맞춤 답글을 만들어주는 걸 해보고 있거든요.

지금 테스트 기간이라 무료로 10건 해드리고 있는데,
혹시 관심 있으시면 리뷰 몇 개 보내주시면 
답글 샘플 만들어드릴까요?
```

**메시지 B (잘 관리하고 있다고 하면)**:
```
오 대단하시네요! 매일 쓰시는 거 정말 쉽지 않은데.

혹시 불만 리뷰 대응할 때 어려운 점은 없으세요?
어떻게 답하면 좋을지 고민되는 경우가 있다고 많이 들어서요.
```

### 4차 DM — 결과 전달 & 후속

**메시지 (샘플 작성 후)**:
```
사장님! 보내주신 리뷰 3개에 대한 답글 만들어봤어요.

[답글 1]
[답글 2]  
[답글 3]

마음에 드시면 바로 복붙하시면 됩니다!
수정하고 싶은 부분 있으면 편하게 말씀해주세요.

이런 식으로 매일 리뷰 답글을 만들어드리는 서비스를 
월 3만원에 하고 있는데, 관심 있으시면 말씀해주세요 😊
```

## 네이버 카페 쪽지 스크립트

### 타겟: 리뷰 관리 관련 질문 올린 사장님

```
안녕하세요! 리뷰 관리 관련 글을 보고 쪽지 드립니다.

저도 지인 가게를 도와주면서 리뷰 답글 쓰는 일이 
생각보다 큰 부담이라는 걸 알게 됐어요.

혹시 관심 있으시면, 리뷰를 보내주시면 
맞춤 답글 샘플을 무료로 만들어드릴 수 있어요.

편하실 때 답변 주시면 감사하겠습니다!
```

## 목표 수치
- **1주차**: 30명 DM → 10명 답변 → 5명 무료 체험 → 1-2명 유료 전환
- **2주차**: 50명 DM → 15명 답변 → 7명 무료 체험 → 2-3명 유료 전환
- **현실 전환율 참고**: DM 답변율 ~30%, 무료→유료 전환율 ~20-30%
