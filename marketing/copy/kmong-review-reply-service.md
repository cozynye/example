# 리뷰 답글 작성 대행 — 크몽 등록

## 플랫폼: 크몽

## 서비스 제목
소상공인 네이버/배달앱 리뷰 답글, 사장님 말투로 자연스럽게 대신 써드립니다

## 카테고리
- IT/프로그래밍 > 업무 자동화
- (대안) 마케팅 > 바이럴마케팅 > 체험단/리뷰

## 서비스 설명

### 이런 분께 추천합니다
- 매일 쌓이는 네이버/카카오맵/배민/요기요 리뷰에 답글 쓸 시간이 없는 사장님
- 복붙 답글 말고 진심 담긴 맞춤 답글을 원하시는 분
- 악성 리뷰에 어떻게 대응해야 할지 고민이신 분
- 리뷰 답글 안 달면 신뢰 떨어지는 거 아는데 시간이 없으신 분

### 서비스 내용
1. 사장님이 리뷰 텍스트를 보내주시면
2. 리뷰 내용(칭찬/불만/중립)과 감정을 분석하고
3. 사장님 가게 특성에 맞는 자연스러운 한국어 답글을 작성합니다

**모든 답글은 사람이 직접 쓴 것처럼 자연스럽습니다.**
- 칭찬 리뷰 → 감사 + 재방문 유도
- 불만 리뷰 → 공감 + 구체적 개선 약속
- 중립 리뷰 → 친근한 인사 + 메뉴 추천

### 작업 과정
1. 가게 정보 전달 (업종, 분위기, 원하는 말투)
2. 리뷰 텍스트 전달 (캡처 or 텍스트)
3. 24시간 내 맞춤 답글 전달
4. 수정 요청 시 1회 무료 수정

### 포함사항
- 가게 프로필 세팅 (첫 주문 시 1회)
- 업종별 맞춤 톤 설정 (카페/음식점/미용실/펫샵)
- 악성 리뷰 대응 가이드 제공

### 불포함사항
- 리뷰 플랫폼 직접 로그인/게시 (사장님이 복붙하시면 됩니다)
- 가짜 리뷰 작성

## 가격 설정
| 패키지 | 가격 | 포함 내용 | 작업일 |
|--------|------|---------|--------|
| 기본 | 30,000원/월 | 월 30건 답글 (일 1건) | 24시간 내 |
| 표준 | 50,000원/월 | 월 60건 답글 (일 2건) + 악성리뷰 대응 | 24시간 내 |
| 프리미엄 | 80,000원/월 | 월 150건 답글 (일 5건) + 리뷰 분석 리포트 | 12시간 내 |

### 가격 전략 근거
- 리뷰닥터(경쟁사): 대형 가맹점 위주, 가격 비공개 (추정 월 5-10만원+)
- 우리 타겟: 동네 가게 사장님 → 월 3만원 진입 가격
- 목표: 기본 패키지 4명 = 월 12만원 (주 3만원) → 표준 업그레이드 시 주 10만원 도달

## 답글 샘플 (포트폴리오용)

### 샘플 1 — 칭찬 리뷰 (카페)
**리뷰**: "분위기 너무 좋고 라떼가 진짜 맛있어요! 다음에 또 올게요"
**답글**: "정성껏 내린 라떼를 알아봐주셔서 감사합니다 ☺️ 다음에 오시면 이번 주 새로 들어온 시즌 블렌드도 추천드려요! 또 뵐 수 있길 바랍니다."

### 샘플 2 — 불만 리뷰 (음식점)
**리뷰**: "음식이 너무 늦게 나왔어요. 30분 넘게 기다렸는데 사과도 없었습니다"
**답글**: "오래 기다리시게 해서 정말 죄송합니다. 당일 주문이 몰려서 정신없이 대응하다가 사과 인사도 놓친 것 같습니다. 다시는 이런 일 없도록 주방 동선을 개선하고 있습니다. 다음에 방문해주시면 더 나은 모습으로 보답하겠습니다."

### 샘플 3 — 중립 리뷰 (미용실)
**리뷰**: "보통이에요. 나쁘지 않은데 특별한 건 없었어요"
**답글**: "방문해주셔서 감사합니다! 혹시 원하시는 스타일이 있으셨는데 충분히 상담이 안 됐다면 다음엔 편하게 말씀해주세요. 고객님 취향에 맞는 스타일을 찾아드리고 싶습니다 😊"
