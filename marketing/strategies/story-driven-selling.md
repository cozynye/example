# 스토리 기반 판매 전략

## 핵심 원칙
> "팔지 마라, 해결하라." - 인디해커 성공 패턴

직접 판매보다 **자신의 고민 → 해결 과정 → 결과물 공유**가 전환율이 높다.

## 프레임워크

### 1. 문제 공감 (Hook)
```
"카페 사장님, 인스타 DM으로 예약 받으시면서
'아 이거 또 놓쳤다' 하신 적 있으시죠?"
```

### 2. 시도와 실패 (Story)
```
"저도 친구 카페에서 예약 관리 도와주다가...
네이버 예약은 카페에 맞지 않고,
캐치테이블은 너무 비싸고..."
```

### 3. 해결책 제시 (Solution)
```
"그래서 직접 만들었습니다.
인스타 프로필 링크에 걸면 끝."
```

### 4. 결과 증명 (Proof)
```
"지금 [N]개 카페에서 사용 중이고,
노쇼가 [X]% 줄었습니다."
```

## 채널별 적용

### 인스타그램 DM (카페 사장 직접)
- 예약제 카페 검색 (#예약제카페, #예약카페)
- 사장님 계정 팔로우 → 피드에 공감 댓글
- 자연스럽게 DM: "사장님, 예약 관리 어떻게 하시나요?"
- 절대 첫 DM에 판매하지 않기

### 커뮤니티 (아프니까사장이다 등)
- "카페 예약 관리 이렇게 해결했습니다" 후기형 글
- 사용 방법 + 스크린샷 포함
- 질문에 성실히 답변 → 신뢰 구축

### 크몽
- "카페 예약 시스템 구축해드립니다" 서비스
- 초기 세팅 + 교육 패키지 (20-30만원)
- 이후 월 구독으로 전환

## 하지 말아야 할 것
- 첫 접점에서 바로 판매하지 않기
- 기능 나열하지 않기 (문제 해결에 집중)
- 과장/마케팅 용어 사용하지 않기
- 스팸성 대량 DM 보내지 않기
